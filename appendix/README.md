## Key terms

| Term | Meaning |
|------|---------|
| bit | one binary digit: `0` or `1` |
| binary | the number system with two digits, `0` and `1` |
| hexadecimal | the number system with sixteen digits, `0` to `9` and `A` to `F`; one digit stands for four bits |
| two's complement | the way negative whole numbers are stored; to change the sign of a number, flip every bit and add 1 |
| namespace | a named group of names; `std` is the namespace of the standard library |
| build system | a tool that keeps the build commands in a file and compiles only what changed, such as Make or CMake |
| interpreter | a program that reads source code and carries it out step by step, as Python does |
| optimise | make a program faster without changing its result; `-O2` asks the compiler to do it |
| SOLID | five design principles for classes that stay easy to change |
| copyright | the author's right to decide who may copy, change and share a work |
| licence | a text in which the author says what everyone may do with a work, and under which conditions |
| open source | source code with a licence that lets everyone use, change and share it |
| copyleft | a licence condition: what you build with the code may only be shared under the same licence |
