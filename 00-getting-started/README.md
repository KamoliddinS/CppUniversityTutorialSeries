# 00 · Getting started

After this chapter your computer is ready: you can build a C++ program, move around in a terminal, and get the course with Git.

| # | Lesson | You learn to |
|---|--------|--------------|
| 1 | [Install the tools](01-install-the-tools/README.md) | install a compiler, VS Code, Git and CMake, and check that they work |
| 2 | [Use the terminal](02-use-the-terminal/README.md) | move between folders and run commands |
| 3 | [Use Git](03-use-git/README.md) | download the course, save your own work, and send a fix |

This chapter has no exercises. Each lesson ends with "Check that it works": commands you run and the result you must see.

## Key terms

| Term | Meaning |
|------|---------|
| CMake | a tool that builds many programs with one command; the course uses it to check your exercises |
| `PATH` | the list of folders where the system looks for a program when you type its name |
| terminal | a window where you type a command and press Enter |
| current folder | the folder a terminal is in; commands work on it |
| path | the name of a file together with the folders that lead to it |
| Git | a program that records versions of the files in a folder |
| GitHub | a website that stores repositories, so that people can share them |
| repository | a folder whose versions Git records |
| clone | your own copy of a repository, on your computer |
| commit | one saved version of your files, with a message |
| fork | your own copy of someone else's repository, on GitHub |
| pull request | a request to the owner of a repository to take your change |
