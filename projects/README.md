# Projects

A project is a larger program that you write on your own, in steps, with tests that tell you when a step is done.

| Project | What you build | Start it |
|---------|----------------|----------|
| [Gradebook](gradebook/README.md) | a program that keeps the students of a group and their scores; it grows in five steps through the semester | after [chapter 05](../05-vectors-and-strings/README.md) |
| [Binary converter](binary-converter/README.md) | a small program that converts numbers between decimal and binary and adds binary numbers; one step | after [chapter 05](../05-vectors-and-strings/README.md) |

## Key terms

| Term | Meaning |
|------|---------|
| command | one line of input that tells a program what to do, such as `add Aziz 85` |
| usage | the correct form of a command, such as `add <name> <score>`; a program prints it when a command is typed wrongly |
| test case | an input file together with the exact output that a correct program prints for it |
| acceptance criteria | the list of things that must be true before a piece of work counts as done |
| starter | the files you get at the beginning of a step |
